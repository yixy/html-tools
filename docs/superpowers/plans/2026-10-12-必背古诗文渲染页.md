# 必背古诗文渲染页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在《中国古代经典文学作品.html》增加「必背古诗文」入口，跳转到新页面用 marked.js 渲染展示 md 内容，支持 URL 参数扩展加载其他篇目。

**Architecture:** 新建一个自包含的静态渲染页 `必背古诗文.html`，读取 `?file=` 参数（默认小学篇），白名单校验后 fetch 同目录 md，用项目已有的 `libs/marked.min.js`（v12.0.2）渲染；渲染后从 `##` 标题自动生成年级锚点导航。主页面在「文言文小贴士」后追加入口区块。

**Tech Stack:** 纯 HTML/CSS/原生 JS，marked v12.0.2（`marked.use` + `paragraph` renderer 覆盖，返回 `false` 回退默认渲染）。无构建步骤，GitHub Pages 静态托管。

**测试说明:** 仓库无测试框架，本计划采用三层验证：① node 无头冒烟脚本（验证渲染逻辑：marked API 兼容性、作者行正则、年级标题数量、换行保留，已验证脚本断言全部通过）；② curl 静态资源可达性检查；③ 浏览器手动清单（锚点跳转、错误场景、移动端）。TDD 的"先写失败测试"在此静态站场景下等价于"先写页面、立即运行冒烟断言"。

        marked.use({

                paragraph: function (text) {
                    if (AUTHOR_RE.test(text) || AUTHOR_NAMES[text]) {
                        return '<p class="author">' + text + '</p>\n';
                    }
                    return false; // 其余段落走默认渲染
                }
            }
        });

        // 文件名白名单：仅允许中英文数字，防路径穿越
        var FILE_RE = /^[\u4e00-\u9fa5A-Za-z0-9]+\.md$/;
        if (!FILE_RE.test(file)) {
            showError('内容不存在或文件名不合法');
            return;
        }

        fetch(encodeURIComponent(file))
            .then(function (res) {
                if (!res.ok) throw new Error('HTTP ' + res.status);
                return res.text();
            })
            .then(function (md) {
                contentEl.innerHTML = marked.parse(md);
                var mh1 = contentEl.querySelector('h1');
                if (mh1) {
                    pageTitle.textContent = mh1.textContent;
                    document.title = pageTitle.textContent;
                    mh1.remove();
                }
                buildGradeNav();
            })
            .catch(function () {
                showError('内容加载失败');
            });

        function buildGradeNav() {
            var hs = contentEl.querySelectorAll('h2');
            var html = '';
            for (var i = 0; i < hs.length; i++) {
                var id = 'grade-' + i;
                hs[i].id = id;
                html += '<a href="#' + id + '">' + hs[i].textContent + '</a>';
            }
            navEl.innerHTML = html;
        }
    })();
    </script>

- [ ] **Step 2: 无头冒烟验证渲染逻辑**

将以下脚本写入 `/tmp/verify-render.js`（不入库，一次性验证用），注意其中的正则与页面内联 JS 保持一致：

```js
const ROOT = '/home/youzhilane/0x37/myworkspace/github.com/yixy/html-tools';
const marked = require(ROOT + '/libs/marked.min.js');
const fs = require('fs');

const AUTHOR_RE = /^[\u4e00-\u9fa5]{1,3}\s*·\s*[\u4e00-\u9fa5]+$/;
const AUTHOR_NAMES = { '汉乐府': 1, '古诗十九首': 1, '北朝民歌': 1, '毛泽东': 1 };
const authors = [];
marked.use({ renderer: { paragraph(text) {
  if (AUTHOR_RE.test(text) || AUTHOR_NAMES[text]) { authors.push(text); return '<p class="author">' + text + '</p>'; }
  return false;
}}});

const md = fs.readFileSync(ROOT + '/pages/literature/语文必背古诗文/小学必背古诗词汇总.md', 'utf8');
const html = marked.parse(md);

const assert = (cond, msg) => { if (!cond) { console.error('FAIL: ' + msg); process.exit(1); } };
assert((html.match(/<h2/g) || []).length === 12, '应有 12 个年级标题');
assert(authors.length === 113, '应有 113 个作者行，实际 ' + authors.length);
assert(authors.includes('唐 · 骆宾王'), '带空格作者行未识别');
assert(authors.includes('唐·白居易'), '不带空格作者行未识别');
assert(authors.includes('汉乐府') && authors.includes('毛泽东'), '总集/作者名未识别');
assert(html.includes('鹅，鹅，鹅，\n曲项向天歌'), '诗行换行未保留');
assert(!authors.some(t => t.includes('\n')), '多行诗句被误判为作者行');
console.log('PASS: 渲染逻辑全部断言通过');
```
