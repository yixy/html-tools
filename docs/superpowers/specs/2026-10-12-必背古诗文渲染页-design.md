# 必背古诗文 md 渲染页设计

日期：2026-10-12

## 背景与目标

《中国古代经典文学作品.html》的「文言文小贴士」区块之后，增加「小学必背古诗文」入口，点击跳转到新页面展示 `pages/literature/语文必背古诗文/小学必背古诗词汇总.md` 的内容。

要求：

- 预留扩展：以后加初中、高中篇目时，只需新增 md 文件并追加一条链接，不用再写页面
- 页面内容长（12 册、130 多首），需要各年级快速跳转导航

## 方案

采用「md 渲染页 + marked.js」方案（用户已确认）：

- md 是唯一数据源，不做 HTML 副本
- 复用项目已有的 `libs/marked.min.js`，与 `数学学习笔记.html` 的 fetch + marked 模式一致
- 年级导航从 md 的 `##` 标题自动生成，不需要手工维护

## 渲染页细节（必背古诗文.html）

### 加载逻辑

- 读取 URL 参数 `?file=小学必背古诗词汇总.md`；无参数时默认加载 `小学必背古诗词汇总.md`
- 文件名白名单校验：`^[\u4e00-\u9fa5A-Za-z0-9]+\.md$`，不允许含 `/`、`..`，防路径穿越
- fetch 失败或文件名非法时，在卡片内显示友好错误提示（中文），不报裸错误
- 资源路径一律用相对路径（`../../../libs/marked.min.js`、同目录 fetch），保证 GitHub Pages（`/html-tools/` 根）与本地 `python3 -m http.server` 都能工作

### 渲染与样式

- `marked.parse` 渲染 md
- 渲染后收集所有 `##`（年级）标题，赋锚点 id，在文章顶部生成年级快速导航条（如「一上 一下 … 六下」），点击平滑滚动（`scroll-behavior: smooth`）到对应年级
- 诗词正文段落保留换行：md 中诗行是连续行（soft break），marked 渲染为一个段落，用 CSS `white-space: pre-line` 显示
- 作者行用 marked 自定义 `paragraph` renderer 识别，输出 `class="author"`，样式为居中、灰色小字。识别规则：段落整体匹配 `^[\u4e00-\u9fa5]{1,3}\s*·\s*[\u4e00-\u9fa5]+$`（兼容 `唐 · 骆宾王` 与 `唐·白居易` 两种空格写法），或恰好等于 `汉乐府`、`古诗十九首`、`北朝民歌`、`毛泽东` 之一
- 整体样式沿用文学页（山海经/诗经）风格：article 卡片、绿色 `#07c160` 主题、顶部「← 返回作品列表」「← 返回首页」两个导航链接、移动端响应式（@media 600px 断点）

## 错误处理

| 场景 | 行为 |
|------|------|
| 无 `?file=` 参数 | 默认加载小学篇 |
| 文件名不合法（含路径分隔符等） | 卡片内提示「内容不存在或文件名不合法」 |
| fetch 404 / 网络失败 | 卡片内提示「内容加载失败」 |
