# 数论启蒙

从整数系统出发，研究了数的性质（整除、因数倍数），进而衍生出“分解质因数”，这是求解“最大公约数”和“最小公倍数”的核心工具（特别是短除法）。

## 1 整数与整除

自然数对加法和乘法封闭，对减法不封闭（引出整数），对除法不封闭（引出分数）。
- **自然数**：如 1, 2, 3, ...   （两自然数相加/积仍为自然数）
- **整数**：包括负整数、零和正整数，如 ..., -2, -1, 0, 1, 2, ...  （考虑减法封闭性引出整数）
- **分数**：由除法引出，如 $1 \div 2 = \frac{1}{2}$  （考虑除法封闭性引出分数）

研究分数时，涉及到约分，需要先引出整除的概念。
- **整除**：设 $a, b, c$ 为整数，且 $b \neq 0$。若 $a \div b = c$ 或 $b \cdot c = a$，则称 $b$ 整除 $a$（记作 $b \mid a$）。

```text
                 (-------------)           真分数范围 (-1, 1) 中的某些点，注意并不全是分数！
<------------------------------------------------> 整数范围 Z 所有整数点
                        [------------------------> 自然数范围 N (0, +∞) 中的整数点
---+------+------+------+------+------+------+--->
  -3     -2     -1      0      1      2      3
```

-   **整除定义**：设 $a, b, c$ 为整数，且 $b \neq 0$，若 $a \div b = c$（或 $b \cdot c = a$）成立，则 $a$ 能被 $b$ 整除，或 $b$ 整除 $a$（记作 $b \mid a$）。

## 2 因数与倍数
-   若 $b \mid a$，则 $b$ 是 $a$ 的因数（约数），$a$ 是 $b$ 的倍数。
-   **关键性质**：
    -   一个数的**最小因数**是 1，**最大因数**是它本身。
    -   一个数的**最小倍数**是它本身，**没有最大倍数**。
    -   一个数的因数是**有限**的，倍数是**无限**的。

-   **10的整除性**：个位为 0 的数可被 10 整除。
-   **2和5的整除性**：个位能被 2 或 5 整除即可。（$10 = 2 \times 5$）
-   **4和25的整除性**：末两位能被 4 或 25 整除即可。（$100 = 4 \times 25$）
-   **8和125的整除性**：末三位能被 8 或 125 整除即可。（$1000 = 8 \times 125$）
-   **3的整除性**：每个数位之和能被 3 整除。（因为高位1退位为10，10/3总余1）
-   **9的整除性**：每个数位之和能被 9 整除。（因为高位1退位为10，10/9总余1）
-   **6的整除性**：能同时被 2 和 3 整除的数。（$6 = 2 \times 3$ 。假设a与b互素，则最小公倍数为ab，一个数如果是两个数的公倍数，那么它一定是最小公倍数的倍数。）
-   **7的整除性**：**截尾法**对于一个整数，去掉个位数字得到前部分，然后计算前部分减去两倍的个位数字。如果结果能被7整除，则原数能被7整除。（如：$984 \rightarrow 98 - 4 \times 2 = 91$，91能被7整除，则984能被7整除）。
-   **11的整除性**：奇数位数字之和 与 偶数位数字之和 的差，能被 11 整除。（$36928: (8+9+3) - (2+6) = 20 - 8 = 12$，12不能，故不能）。

## 4 质数（素数）、合数与分解质因数
-   数论讨论范围一般限于**正整数**。
    -   **质数（素数）**：只有 1 和它本身两个因数（如：$2, 3, 5, 7, \dots$）。
    -   **合数**：除了 1 和它本身外，还有其他因数。
    -   **1**：既不是质数，也不是合数。
-   **寻找质数**：使用**筛法**。例如找1到50的质数：① 划掉1；② 保留2，划掉2的倍数；③ 保留3，划掉3的倍数；④ 保留5，划掉5的倍数……

## 5 奇数与偶数
-   **定义**：能被2整除的正整数为偶数（$x = 2n$）；不能被2整除的为奇数（$x = 2n+1$）。
-   **运算特性**：
    -   偶数 $\pm$ 偶数 = 偶数（偶数 $\times$ 偶数 = 偶数）
    -   奇数 $\pm$ 奇数 = 偶数（奇数 $\times$ 奇数 = 奇数）
    -   偶数 $\pm$ 奇数 = 奇数（偶数 $\times$ 奇数 = 偶数）

## 6 最大公约数与最小公倍数
-   **定义**：
    -   若存在正整数 $c$ 满足 $c \mid a$ 且 $c \mid b$，则 $c$ 是 $a, b$ 的公因数，其中最大的称为**最大公约数**（记作 $(a,b)$）。两个数的最小的公因数是 1。
    -   若存在正整数 $c$ 满足 $a \mid c$ 且 $b \mid c$，则 $c$ 是 $a, b$ 的公倍数，其中最小的称为**最小公倍数**（记作 $[a,b]$）。
  
-   **求最大公约数的方法**：
    1.  **短除法**（连续除以公共质因数，直到互质为止）。
    2.  **辗转相除法**（欧几里得算法）：用大数除以小数，得到余数；再用除数除以余数，重复此过程，直到余数为 0，最后的除数即为最大公约数。


```text
# 短除法求 180 与 108 的最大公因数（GCD）

        2 │ 180   108
        ──┼─────────
        2 │  90    54
        ──┼─────────
        3 │  45    27
        ──┼─────────
        3 │  15     9
        ──┼─────────
               5     3


说明：最大公因数 = 左侧所有除数相乘
      即： 2 × 2 × 3 × 3 = 36
```

```text
+---------------------------------------------------------------------------+
|             辗转相除法 (欧几里得算法) 求 180 和 108 的最大公约数            |
+---------------------------------------------------------------------------+

             [ 180 ] 与 [ 108 ]
                   |
                   v
+---------------------------------------------------------------+
|   180 ÷ 108  -->  商 = 1,  余数 = 72    ( 余数不为 0，继续 )   |
+---------------------------------------------------------------+
                   |
                   v
+---------------------------------------------------------------+
|   108 ÷  72  -->  商 = 1,  余数 = 36    ( 余数不为 0，继续 )   |
+---------------------------------------------------------------+
                   |
                   v
+---------------------------------------------------------------+
|    72 ÷  36  -->  商 = 2,  余数 =  0    ( 余数为 0，停止 )     |
+---------------------------------------------------------------+
                   |
                   v
+---------------------------------------------------------------------------+
|  结论：余数等于 0 时，此时的除数 36 即为最大公约数。                       |
|  即： gcd(180, 108) = 36                                                   |
+---------------------------------------------------------------------------+
```


-   **求最小公倍数的方法**：
    1.  **短除法**（与求GCD类似，但要乘到最后一排互质的数）。
    2.  **公式法（重要关联）**：**正整数 $A \cdot B =$ 最大公约数 $\times$ 最小公倍数**。
-   **互素**：两个数的最大公约数为 1。素数之间必然互素，合数之间也可能互素（如 4 和 9）。

```text
# 短除法求 180 与 108 的最小公倍数（LCM）

        2 │ 180   108
        ──┼─────────
        2 │  90    54
        ──┼─────────
        3 │  45    27
        ──┼─────────
        3 │  15     9
        ──┼─────────
               5     3


说明：最小公倍数 = 左侧所有除数 × 底部最后的互质数
      即： 2 × 2 × 3 × 3 × 5 × 3 = 540
```



## 分数与除法的关系
-   分数和除法的关系：若存在正整数 $p, q$，则有 $p \div q = \frac{p}{q}$（其中 $q \neq 0$）。
-   **本质意义**：两者本质上是一样的，都可以从“平均分”的角度去考虑。
    -   **除法**：把 $p$ 平均分成 $q$ 份，每份是几？
    -   **分数**：$p$ 的 $q$ 分之一是几？（本质也是把 $p$ 平均分成 $q$ 份，求其中1份的值）。

## 分数的分类与互化
-   **真分数**：分子比分母小，数值 $< 1$。
-   **假分数**：分子大于等于分母，数值 $\ge 1$。
-   **带分数**：由整数部分和真分数部分组成，是假分数的另一种表示形式（即包含一个整数和一部分真分数）。
-   **转换示例**：$11 \div 4 = 2 \dots 3 \implies \frac{11}{4} = 2 + \frac{3}{4} = 2\frac{3}{4}$。
    -   被除数 = 除数 $\times$ 商 + 余数。
    -   假分数（分子是被除数，分母是除数） = 整数部分 + 真分数 = 带分数（整数部分为商，分子为余数，分母为除数）。
