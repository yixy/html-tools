# 概率统计启蒙

## 1 分类
学会按颜色、大小、男女等进行分类，也可以自己定义分类规则。通过归纳总结，更好地明白事物的规律以及存在的关系。

* 分类的方法：使用表格。

##  2 认识概率
* **一定会发生的事件**：在任何情况下都会发生的事件。
* **不可能发生的事件**：在任何情况下都不会发生的事件。
* **可能发生的事件**：在某种情况下会发生，而在其他情况下不会发生的事件。

**在摸球问题中，某种颜色的球数量越多，则摸到的可能性越大；反之，数量越少，则摸到的可能性越小。** 如果题目中没有告诉我们具体的数量，我们就要先进行计算，再比较数量多少，从而判断可能性大小。

## 3 概率与统计

小学数学中的“统计与概率”主要目标是帮助学生建立**数据意识**，并初步感受随机现象。为了让你快速了解主要内容，这里有一个表格汇总了核心知识点。

- **统计与概率**：数据的分类、收集、整理和表达（如绘制统计图表），随机现象发生的可能性（可能性大小），简单数据的分析。

| 学习领域            | 核心内容                                                       | 关键知识点                 |
| --------------- | ---------------------------------------------------------- | --------------------- |
| **数据分类**        | 学习如何根据事物的不同属性（如颜色、形状、用途）确定标准进行分类。                          | 数据分类、简单统计表、调查与记录      |
| **数据的收集、整理与表达** | 学习如何收集数据（如调查、测量），并运用统计表、统计图（条形图、折线图、扇形图）以及平均数等来整理、描述和分析数据。 | 条形统计图、折线统计图、扇形统计图、平均数 |
| **随机现象发生的可能性**  | 通过试验和游戏，感受生活中的随机现象，并能用“可能”、“一定”、“不可能”等词语进行定性描述，感受可能性的大小。   | 确定与不确定现象、可能性大小、游戏公平性  |
